# KhelMaidan V4 Branding

This build adds the KhelMaidan mountain/KM identity across the site.

## Included
- `public/images/khelmaidan-mark.svg` — square KM mountain mark for favicon/CMS.
- `public/images/khelmaidan-logo.svg` — horizontal KhelMaidan header/footer wordmark.
- Site favicon metadata updated in `src/layouts/SiteLayout.astro`.
- Header/footer branding updated to use the new wordmark.
- Responsive logo sizing added to `src/styles/global.css`.
- Sveltia CMS favicon/logo updated in `public/admin/` and `src/pages/admin/index.astro`.

## Test locally
Run `npm install` if needed, then `npm run build` and `npm run dev`.
